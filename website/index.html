A local CMS sandbox for what agents build.

Give your coding agent a disposable Joomla or WordPress site in one command. Mount extensions, run Blueprints headlessly, verify live HTTP responses, and export portable .zip snapshots—without installing PHP, Apache, or MySQL.

Copy an agent prompt → Build a CLI command
$ npx cms-playground start --joomla --auto-mount

Why @cms-playground for agents

Coding agents are great at writing Joomla extensions, WordPress plugins, and themes—until they need a live CMS to actually test what they wrote. Docker stacks are slow to boot, local PHP versions drift, and shared databases leak state between runs.

@cms-playground runs real PHP inside WebAssembly via @php-wasm/node with SQLite out of the box. Your agent runs a single terminal command, gets a clean local URL and admin credentials, verifies its changes against a real runtime, and throws the sandbox away when done.

Every workflow is scriptable. Use --auto-mount to detect and activate the project in the current directory, run-blueprint to execute declarative JSON setup headlessly in CI, or build-snapshot to package the configured site into a portable .zip archive.

Zero-setup PHP-WASM

Boots Joomla (5.4, 6.2) and WordPress (6.7+) on PHP 7.4–8.5. Bundles cache locally in ~/.cache/cms-playground for instant repeat runs.

Auto-mount & verify

Pass --auto-mount to detect Joomla XML manifests or WordPress plugin/theme headers, mount them via NODEFS, and run discovery or activation automatically.

Headless Blueprints & CLI

Chain runPHP, writeFile, runSql, setSiteOption, or forward directly to cli/joomla.php with cms-playground cli --joomla -- user:list.

Copy-pasteable agent prompts

Paste any prompt directly into Claude Code, Cursor, Codex, Antigravity, or Gemini CLI. Each one tells your agent the exact @cms-playground command and verification step.

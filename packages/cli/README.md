# @cms-playground/cli

Run a local CMS in PHP WebAssembly. Use Node.js 24.18 or later and npm 11.16 or later.

```sh
npx @cms-playground/cli list
npx @cms-playground/cli start --wp
npx @cms-playground/cli start --joomla
npx @cms-playground/cli start --drupal
npx @cms-playground/cli start --typo3
npx @cms-playground/cli start --kirby
```

The first run downloads the CMS. Open the local URL printed by the CLI and press Ctrl+C to stop the server.

[CLI options and examples](https://github.com/fellyph/cms-playground/blob/main/docs/GETTING-STARTED.md)
